# Temas

La numeración y los títulos siguen la «Relación detallada y ordenación
temporal de los contenidos» del proyecto docente del curso 2026--2027.

Cada carpeta contiene un `tema.tex` y las subcarpetas `teoria/` y
`ejercicios/`. Los nuevos archivos deben representar unidades temáticas
coherentes y ser incluidos explícitamente desde el `tema.tex` correspondiente.
